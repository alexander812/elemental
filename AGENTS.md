# Lexi — инструкции проекта

## Ответы (без мусора)

- Только суть: результат → файлы (`путь:строки`) → проверка → риски/что осталось.
- Без вступлений, похвал, повторов запроса, пересказа очевидного и рассуждений вслух.
- Не выводить код и большие листинги — ссылаться на файлы и строки.
- Короткие пункты; развёрнутые пояснения — только по прямой просьбе.
- Непроверенное помечать: «предположение», «не проверял».

## Проверки

- Перед сдачей: `npm run lint`, `npm run typecheck`, `npm run build`.
- e2e — Playwright-скрипты в `$TMPDIR/opencode/e2e` (вне репозитория, не коммитятся), пример — `cards-test-mode.cjs`; команды и сценарии — PROJECT.md «Проверка изменений».

## Данные

- Меняются модели (`app/src/lib/types.ts`, форматы `transport/*`) → поднять `DATA_VERSION` (`lib/storage.ts` + литерал в `app/index.html`) и `BACKUP_VERSION` (старые данные удаляются). Подробности — PROJECT.md «Версионирование данных».

## Карта проекта

- `PROJECT.md` — основная карта (архитектура, экраны, модель данных). Читать нужные разделы перед работой с фичей, целиком не перечитывать.
