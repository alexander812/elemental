# 🎨 Промпты для генерации изображений персонажей и локаций

> Единый визуальный стиль для всего курса. Рекомендую **мягкую акварель в стиле детской книжки-иллюстрации** — она дружелюбная, универсальная и хорошо подходит для учебных материалов.

## 🎨 Общий стиль (использовать в каждом промпте)

**Базовый стиль-суффикс** (добавлять в конец каждого промпта):

```
soft watercolor children's book illustration, warm pastel palette, gentle line art, cozy and friendly atmosphere, natural lighting, high detail, white background, full body portrait
```

**Для локаций** заменить финал на:

```
soft watercolor children's book illustration, warm pastel palette, gentle line art, cozy and friendly atmosphere, wide establishing shot, detailed background, no people
```

**Технические параметры (для Midjourney / SD):**

```
--ar 2:3 --style raw --stylize 250   (портреты)
--ar 16:9 --style raw --stylize 250  (локации)
```

## 📌 Советы по использованию

1. **Единый стиль** — обязательно добавляй «soft watercolor children's book illustration» в конце каждого промпта, чтобы все картинки смотрелись как одна серия.

2. **Консистентность персонажей.** Если генерируешь одного героя много раз, добавляй в промпт ключевые черты: цвет волос, возраст, одежда. Например, для Анны:
   ```
   [Anna], 42 years old, dark brown hair in a neat bun, light blue medical coat
   ```

3. **Для Midjourney** удобно использовать `--cref <URL>` (character reference) — загружаешь одно удачное изображение героя и ссылаешься на него для остальных сцен.

4. **Для Stable Diffusion** — LoRA или IP-Adapter с референсным изображением дадут ту же консистентность.

5. **Для DALL·E 3** — можно просто копировать промпт, он хорошо работает с длинными описаниями.

6. **Порядок генерации:** сначала портреты всех персонажей → потом локации → потом сюжетные сцены. Так проще поддерживать стиль.

7. **Размеры:**
   - Портреты персонажей: `--ar 2:3` (вертикальные)
   - Локации: `--ar 16:9` (горизонтальные)
   - Сцены: `--ar 3:2` или `--ar 16:9`
