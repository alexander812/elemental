# Структурированные задания: Полиглот

`ui/PhraseTaskView.tsx` — страницы теории с таблицами и тест «Собрать фразу». `ui/usePageMotion.ts` — горизонтальная карусель без наклона, scale и затухания: фактическая координата x обновляется через RAF, переход LEAVE_MS=260 и возврат за 200ms. В покое монтируется одна страница; в движении — только пересекающие viewport панели (максимум две), без скрытых соседей и промежуточных страниц. Reduced motion переключает сразу, без монтажа preview.

`ui/PagePanel.tsx` — абсолютная панель содержимого с собственным вертикальным скроллом. Ключ панели — индекс страницы: preview становится текущей без перемонтирования. Preview inert и aria-hidden, не проверяет ответы и не запускает озвучку/салют; заголовки имеют уникальные id. Черновик ответа и позиция скролла хранятся в родителе и восстанавливаются после ухода панели из viewport. Они не входят в сохраняемые данные. Иконка оглавления — штатная IconViewList, открывает прежний BottomSheet.

Кнопки навигации есть в теории и на странице слов: иконки ‹ / › у левого и правого края под каруселью, штатный ButtonIcon secondary с доступными названиями Back / Next / Start test. Единственная пара стрелок находится вне viewport и панелей, остаётся неподвижной при свайпах и блокируется до окончания движения. Тест листается свайпом или автоматически после ответа. Фиксированный счётчик включает все страницы; штатный BottomSheet перечисляет учебные и тестовые страницы. Контент уроков 1–16 — `courses/poliglot/course_poliglot_01.en.json` … `course_poliglot_16.en.json`, парсер — `courses/poliglot/lesson-one.ts`.

Данные — `CardSet.phraseTask` в `lib/types.ts`; `transport/sets.savePhraseTaskProgress` сохраняет страницу и проверяет ответ через `lib/phraseAnswer.ts`, выставляет `examPassed` только по всем вопросам. Effector: `features/sets/store.savePhraseTaskProgressFx`. Последняя страница и решённые вопросы входят в общий бэкап. Счётчики/галочки задания и урока переиспользуют общий прогресс.

Инварианты: переходы не решают вопросы; правильные ответы сохраняются после исправлений; банк не содержит альтернативного правильного ответа, объявленного ошибкой. На вопрос даётся три попытки: третья ошибка фиксирует неуспех этого вопроса до нового запуска и автоматически переводит вперёд. `model/testRun.ts` считает ошибки и непроверенные вопросы; результат с любым из них — непройденный. Попытки/ошибки текущего запуска живут в родителе, переживают свайпы и меню, сбрасываются при выходе/перезагрузке. Только solved/pageIndex сохраняются постоянно. «Начать сначала» через `restartPhraseTaskFx` очищает только тест и возвращает на первую страницу, не изменяя карточки. Счётчик не меняется на результате. Без обязательного микрофона и карточного меню. Контент ru → en независимо от языка интерфейса; UI react-intl с английским defaultMessage. Контент может прокручиваться вертикально при недостатке высоты/увеличенном шрифте, обрезать нельзя.

Категории «Упражнений» (`courses/poliglot/exercises.ts`) используют гибрид: обычные `cards` для изучения, `phraseTask` — 15 вопросов итогового теста. Кнопка «Тест» карточек открывает этот экран; назад и «Вернуться к обучению» возвращают в карточки, «Следующее задание» открывает следующую колоду. Решение фраз не меняет выученные карточки. Учебные задания без карточек по-прежнему открывают теорию напрямую.

Проверка: обязательные корневые lint/typecheck/build/i18n, мобильный e2e в `$TMPDIR/opencode/e2e`.

Английские inline-формы разбиваются на безопасные React-сегменты и получают `accent-text-and-icons`. В строковой ячейке `форма\nперевод` перевод выводится отдельной строкой; сохраняемая модель не расширяется. Матрица с заголовками «Вопрос / Утверждение / Отрицание» состоит из трёх столбцов без боковой колонки времён: все ячейки тела — `td`, переносы строк сохраняются, размеры адаптированы для телефона. Вступительная страница первого задания объясняет порядок строк (будущее, настоящее, прошлое) перед матрицей. В трёх словарных таблицах кнопки `IconSound` вызывают существующий `speakFx({ text: форма, lang: 'en' })`; браузерная речь отменяется при уходе, native speak заменяет предыдущий (команды native stop пока нет).

Завершение: общий `ExamSmiley`, `Confetti` и `playTestSuccess`; запуск только из успешного ответа при первом переходе `examPassed` в true, а не из рендера/восстановления. Неуспех использует штатный playDisappointment без конфетти. Конфетти учитывают reduced motion. `fetchSets` обновляет страницы поставляемого Полиглота из текущего контента по имени задания, сохраняя id. При изменении страниц `solved` переносится по паре «русское задание + нормализованный ответ», `pageIndex` — по совпавшему вопросу или заголовку теории (иначе ограничивается новым диапазоном), `examPassed` вычисляется по новым вопросам. В первом уроке пять учебных заданий: 5/3/8/3/9 вопросов, все глаголы каждого задания, максимум 10; всего 52 страницы (19 учебных + 5 словарных + 28 вопросов). Итоговый тест проверяет девять глаголов и девять ячеек матрицы по одному разу. В отдельном разделе «Упражнения» остаётся 15 вопросов на категорию по явному уточнению пользователя.

Проверка фразы: крестик внутри поля очищает выбранные слова и возвращает их в банк, не меняя попытки и прогресс. Видимого блока Correct/ошибки/остатка попыток нет; результат объявляется screen reader. После Check поле на 380 мс блокируется и вспыхивает зелёным без движения при верном ответе или красным с горизонтальным shake при ошибке; reduced motion оставляет статичную подсветку. Звуки и вибрация — общие playSuccess/playError и vibrateSuccess/vibrateError, только из активной проверки, без запуска при восстановлении или preview. Повторная попытка доступна после завершения подсветки и заново запускает анимацию. Ошибка сохранения показывается отдельно.

Уроки 2–16: отдельные JSON с пятью заданиями, явными страницами теории и вопросами (не более 10 на задание), итоговое задание объединяет темы урока. Метаданные регистрируются в `course_poliglot.en.json`, файлы загружаются асинхронно только при открытии соответствующего урока.

Перед первым вопросом каждого из 80 заданий уроков 1–16 вставляется страница `vocabulary`: таблица выражений и «Выучить» / «Выучено». `transport/poliglot-vocabulary.ts` загружает пару обычных CatalogCourseData JSON (`course_poliglot_vocabulary.en.json` / `.ru.json`); индексы уроков и заданий совпадают с манифестом. По клику создаётся временный набор в `transport/temporary-sets.ts`, маршрут `vocabulary-cards` открывает стандартные карточки без меню, текста и редактора. `$cardSets` включает RAM-наборы; `$sets`, списки, бэкап и localStorage их не содержат. Шапка «назад» и успешный тест возвращают на ту же страницу слов; успешные результаты скрыты. `phraseTask.vocabularyPassed` сохраняется отдельно от основного фразового теста; перезапуск фраз его сохраняет, полный сброс задания очищает. Native session сохраняет родительский маршрут вместо временного. RAM-наборы очищаются после окончания перехода при выходе.
