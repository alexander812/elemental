# Lexi — описание проекта

Мобильное веб-приложение для заучивания слов по флеш-карточкам. Монорепозиторий с собственной дизайн-системой (иконки + ui-kit). Язык интерфейса — русский.

## Репозиторий

```
app/                      # @elemental/app — само приложение
design-system/icons/      # @elemental/icons — SVG-иконки (React)
design-system/ui-kit/     # @elemental/ui-kit — компоненты, токены, темы, Storybook
skills/new-project/       # скил opencode для скаффолдинга проектов
skills/new-course/        # скил opencode: новый готовый курс и новый язык (JSON по языкам, каталог, валидатор)
PROJECT.md                # этот файл
```

Монорепо: npm workspaces (`["app", "design-system/*"]`) + lerna. Корневые скрипты (lerna run): `dev`, `build`, `lint`, `typecheck`, `generate-tokens`, `storybook`.

- `app`: React 19, Vite 8 (rolldown), TypeScript, Effector 23 + effector-react, CSS Modules + PostCSS (pcss), `@fontsource-variable/inter`.
- `ui-kit`: Vite 7 + Storybook 9 (`@storybook/react-vite`), `postcss-nested`, `classnames`.
- Пакеты отдаются исходниками (`main/types: ./src/index.ts`), без шага сборки.
- Платформенные бинарники (esbuild, rollup, rolldown, lightningcss) ставятся только через optional-зависимости самих пакетов из полного lockfile; `overrides` в корне нет.

## Версионирование данных

- Миграции не делаем. При любом изменении моделей данных (`lib/types.ts` и форматы в `transport/*`) нужно поднять `DATA_VERSION` в `app/src/lib/storage.ts` — старые данные из localStorage при этом не преобразуются, а удаляются.
- Каждое значение в localStorage хранится в конверте `{ version, data }` (ключи по-прежнему `app.<key>`). `save` пишет конверт, `load` при обращении к ключу сверяет `version` с текущим `DATA_VERSION`: при несовпадении (или отсутствии/повреждении конверта) ключ удаляется и возвращается fallback, после чего работает обычный seed. То же касается `app.session`.
- Inline-скрипт темы в `app/index.html` читает `app.settings` из конверта (литерал `DATA_VERSION` синхронизирован с `lib/storage.ts`).
- Импорт бэкапов поддерживает только текущий формат (`BACKUP_VERSION` в `transport/backup.ts`), старые форматы не читаются — «Не удалось прочитать файл».

## Деплой (Vercel)

- Настройки проекта: Root Directory — корень репозитория; сборка описана в корневом `vercel.json` (`installCommand: npm ci`, `buildCommand: npm run build --workspace @elemental/app`, `outputDirectory: app/dist`, `framework: null`). Node 22.
- Критично: `package-lock.json` обязан содержать платформенные optional-пакеты (`node_modules/rolldown`, `node_modules/lightningcss-*`, `@rolldown/binding-*`, `@rollup/rollup-*`, `@esbuild/*`). Если их нет, чистая установка на Linux оставляет Vite 8 без `rolldown` и сборка падает (`ERR_MODULE_NOT_FOUND: Cannot find package 'rolldown'`).
- Нельзя добавлять платформенные пакеты прямыми зависимостями и нельзя использовать `overrides` (например, для esbuild): на чужой платформе npm падает с `EBADPLATFORM` на платформенных optional-пакетах. Платформы обеспечивает только полный lockfile.
- Проверка целостности lock: `grep -c '"node_modules/rolldown"' package-lock.json` и `grep -c 'lightningcss-linux-x64-gnu' package-lock.json` (должны быть > 0).
- Пересоздавать lock только в чистой копии репозитория без `node_modules` (`npm install`), после чего проверять сценарий Vercel: свежая копия → `npm ci` → `npm run build --workspace @elemental/app` → `app/dist/index.html`.

## Модель данных

```ts
Card      { id, texts: { [lang]: string }, learned, deleted, voiceCheck: boolean | null, writeCheck: boolean | null }
CardSet   { id, lessonId, name, active, order, swapped, examPassed: boolean, texts: { [lang]: string }, cards: Card[] }
Lesson    { id, courseId, name, order }
Course    { id, name, description, order, lang, level?: CourseLevel }
Settings  { theme: 'dark' | 'light', userLang, learnAfterChecks: boolean }
```

- Иерархия: курс → уроки → задания → карточки. Задания принадлежат уроку (`CardSet.lessonId`), уроки — курсу (`Lesson.courseId`). Курсы создаются/редактируются на экранах `features/courses`, уроки — на экране уроков (`features/lessons`); удаление урока — свайпом вправо с подтверждением, каскадом удаляет все свои задания (`transport/lessons.deleteLesson` + `transport/sets.deleteSetsByLesson`). Курсы не удаляются (один курс всегда выбран).
- `Course.level` (`CourseLevel`: `beginner`, `elementary`, `intermediate`, `upper-intermediate`) — уровень готового курса из каталога (`features/course-search`); у созданных вручную курсов поля нет. По паре «уровень + название» определяется дубликат при загрузке готового курса.
- Ключи localStorage: `app.courses`, `app.lessons`, `app.sets`, `app.seeded`, `app.settings`, `app.session` (значения — в конверте `{ version, data }`, см. «Версионирование данных»).
- Пара языков глобальная: `Settings.userLang` (язык пользователя, родной) и `Course.lang` (язык курса, изучаемый). `Card.texts` хранит тексты карточки по языкам, `{ ru: 'Понедельник', en: 'Monday' }`; лицевая сторона карточки по умолчанию показывает текст языка курса, обратная — языка пользователя, у задания `CardSet.swapped` меняет стороны местами (звук следует за стороной, проверки — нет). Помощник — `lib/cards.ts: getCardText(card, lang)` (с фолбэком на любой доступный язык); `remapTexts(texts, userLang, courseLang)` берёт тексты под языками пользователя/курса (используется при переносе задания в другой курс).
- `CardSet.texts` хранит текст задания по языкам (`{ ru: '...', en: '...' }`) — исходный текст с экрана «Текст задания» (`features/set-text`) и редактора `features/text-add`. Текст сохраняется по «Сохранить»: для существующего задания — `updateSetTextFx` → `transport/sets.updateSetText(setId, lang, text)`, для черновика в `set-create` — `draftTextSaved` → `$draftTexts` и создание/обновление задания (`createSet`/`updateSet` с `texts`); на экране «Текст задания» по нему строятся сегменты и создаются карточки, там же пустую сторону можно перевести целиком (`translateSetTextFx`: `translateText` + `updateSetTextFx`/`draftTextSaved`). При переносе задания в другой курс тексты ремапятся (`remapTexts`).
- `learned` — карточка выучена (свайп влево), `deleted` — мягко удалена (свайп вверх или «Удалить все карточки»), такие карточки не показываются в колоде и счётчиках, но восстанавливаются.
- `voiceCheck`/`writeCheck` — результат проверки произношения и ввода на карточке (обе проверяют язык курса, кнопки — только на лицевой стороне): `null` (не проверялась), `true` (успех), `false` (ошибка); у новых карточек `null`. `updateCardChecks(setId, cardId, checks)` точечно обновляет значения; импорт бэкапа принимает только текущий формат.
- `Settings.learnAfterChecks` (по умолчанию `false`) — экран «Проверки»; при включении карточка через 2 секунды после успешной второй проверки автоматически уезжает в выученные. `Settings.userLang` (по умолчанию `ru`) — язык пользователя, меняется на экране «Язык».
- Seed: нулевой курс «Знакомство с Лекси» (`lang: en`) → урок «Урок 1» → задание «Приветствие» (без карточек), текст — приветствие Лекси на всех языках каталога (`transport/courses.ts` + `transport/lessons.ts` + `transport/sets.ts`).
- `readCourses`/`readLessons` при отсутствии ключа создают «Знакомство с Лекси» (`lang: en`) и «Урок 1»; `readSets` при `app.seeded = false` засеивает задание «Приветствие» с текстом на 7 языках и пустой колодой. Миграций старых форматов нет — несовпавшая версия данных удаляется (см. «Версионирование данных»).
- `deleteSetsByLesson(lessonId)` — удаление всех заданий урока (каскад при удалении урока).
- `restoreCards(setId, cardIds)` — `deleted=false, learned=false` (возврат в невыученные).
- `resetSet(setId)` — сброс задания к первоначальному состоянию: всем карточкам `learned=false, deleted=false, voiceCheck=null, writeCheck=null`, заданию `examPassed=false` (тексты и id сохраняются).
- `examPassed` — экзамен задания пройден (все ответы верны): ставится по завершении теста (`setSetExamPassed`), снимается, если последняя попытка была с ошибками, и сбрасывается вместе с `resetSet`. По нему в списке заданий и в списке уроков (если все активные задания урока пройдены) показывается зелёная галочка.
- `updateCard(setId, cardId, texts)` — перезаписывает `texts` карточки под языками пользователя/курса.
- `updateSetText(setId, lang, text)` — сохраняет текст задания под языком (`CardSet.texts`).

## Языки

- Каталог языков — `LANGUAGES_CATALOG` в `lib/languages.ts` (7 записей: `ru Русский`, `en English`, `es Español`, `fr Français`, `it Italiano`, `zh 中文`, `de Deutsch`); `LanguageCode = string`, `getLanguageName(code, languages)` с фолбэком на код.
- Все языки каталога доступны сразу — отдельного добавления/удаления языков нет, `$languages` в `features/languages/store` — константный стор с каталогом.
- Дефолты: язык пользователя — русский (`DEFAULT_USER_LANG`), язык курса — английский (`DEFAULT_COURSE_LANG`).
- Язык пользователя задаётся в настройках: меню «Настройки» → «Язык» (`features/settings/ui/LanguageView.tsx`, экран `language`) — список всех языков каталога (Radio), выбор сохраняется в `Settings.userLang` (`setUserLangFx` → `transport/settings.saveUserLang`).
- Язык курса задаётся на экране создания/редактирования курса (`features/courses/ui/CourseCreateView.tsx`) одним `Select` («Язык курса»); язык пользователя в списке недоступен, одинаковые языки запрещены.
- Уроки наследуют язык из курса и не меняют его: на экране урока (`features/lessons/ui/LessonCreateView.tsx`) можно выбрать курс (перенести урок) и видеть его язык. Язык курса — значение по умолчанию для новых заданий; у задания своей пары языков нет. Перенос задания в урок другого курса меняет язык курса: тексты пар переносятся по языковым ключам (`remapTexts`), поэтому текст нового языка (если его не было) даёт пустое поле.
- Создание карточки (`CardCreateView`) пишет тексты под языками пользователя/курса; перевод (`transport/translate.ts`, ISO-код) и озвучка (`transport/speech.ts`, локаль по коду) работают для языков каталога. `speak()` выбирает способ сам: при наличии моста — нативный `speak`, иначе Web Speech API (`canSpeak()` учитывает оба варианта).

## Навигация (`features/navigation/store`)

- Состояние `$nav: { stack: Screen[], transition }`; события `pushScreen`, `popScreen`, `replaceScreen` (заменяет верхний экран стека), `popTo`, `goToRoot`, `transitionEnded`; производные `$stack`, `$screen`, `$transition`, `$canGoBack`.
- Экраны: `courses` (корень), `course-create{courseId?}` (создание/редактирование курса), `course-search` (поиск готовых курсов), `lessons` (уроки текущего курса), `lesson{lessonId}` (задания урока), `lesson-create{lessonId?, courseId?}` (создание/редактирование урока), `set-create{setId?, lessonId?}` (создание; с `setId` — редактирование задания), `cards{setId}`, `set-exam{setId}` (экзамен задания), `set-intro{setId}` (приветственный экран задания), `set-text{setId}` / `set-text{draft}` (текст задания), `card-create{setId, cardId?}`, `cards-restore{setId}`, `text-add{setId}` / `text-add{draft}` (редактор текста), `words-translate{setId}`, `settings`, `theme`, `language`, `voices`, `checks`, `data`, `export`. Вкладки футера «Курсы» и «Уроки» — корневые страницы: `goToRoot` сбрасывает стек к `courses`, `goToLessons` — к `lessons` (текущий курс — `$currentCourseId`).
- `popTo(name)` срезает стек до последнего экрана с таким именем (например, после добавления карточек из текста — `popTo('cards')`).
- Анимации (`AppLayout.tsx` + `AppLayout.module.pcss`): при push новый экран выезжает слева (`slide-in-left`, класс `screenEntering`); при pop уходящий экран уезжает влево оверлеем (`slide-out-left`, класс `screenExiting`, очистка по `animationend` и таймауту 400мс через `transitionEnded`). При смене экрана `main` скроллится вверх. Учитывается `prefers-reduced-motion`.
- `lib/ghostClick.ts`: после навигации включается подавление совместимых mouse-событий (mousedown/mouseup/click) без предшествующего `pointerdown` — защита от «призрачного» клика по новому экрану после тач-тапа (иначе, например, вход в задание автоматически переворачивал карточку). Suppressor «взводится» на `pushScreen`/`popScreen`/`replaceScreen`/`goToRoot`.

При выборе уровня `fetchCatalogFx` грузит `transport/catalog.fetchLevelCatalog` (JSON из `app/src/courses`, через `import.meta.glob` — файл попадает в отдельный чанк); при смене языка повторная загрузка не делается. Список — карточки `Card`: слева `Checkbox` выбора, справа название курса на языке пользователя и язык курса в скобках (`i18n`), под заголовком описание на языке пользователя (две строки с обрезкой); тап по карточке переключает выбор (`courseToggled`, ключ — `entry.course`). Внизу «Загрузить» (`position: sticky; bottom: 0`, показывается после выбора уровня; неактивна без выбранных курсов) — по тапу `loadCoursesFx` показывает лоадер, грузит JSON выбранных курсов на языке курса и языке пользователя (`fetchCatalogCourse`: из каталога берётся пара файлов `course_NN_*.{lang}.json`, в каждом — только один язык), собирает модели (`buildReadyCourses`: курс с `lang` и `level`, уроки из `lessons` с именами из файла языка пользователя (фолбэк — язык курса), задания из `tasks` с именами оттуда же, `texts` и карточки (слова попарно по индексу) — из текстов и слов обоих файлов) и проверяет дубликаты по «уровень + название»: если такие курсы уже есть — `ConfirmSheet` «уже есть у вас. Заменить?» с «Заменить» (`replace: true`) и «Отмена» (загрузка отменяется). При замене старые курсы с их уроками и заданиями каскадно удаляются (`applyReadyCourses`), новые добавляются, `$courses`/`$lessons`/`$sets` обновляются через `.on(loadCoursesFx.doneData)`; по завершении — `showToast('Загрузка успешно завершена')` (in-app сообщение сверху, `shared/ui/Toast`) и `goToRoot`. Состояние экрана при входе сбрасывается (`screenOpened`).

Удаление — bottom sheet (`ConfirmSheet`) с выбором «Удалить курс и уроки» (`deleteCourseFx` режим `with-lessons` — каскадом удаляются уроки и их задания), «Удалить только курс» (режим `course-only` — уроки переносятся в базовый курс) и «Отмена»; после удаления текущим становится базовый курс. Список уроков курса по порядку, перед именем урока — зелёная галочка, если экзамены всех активных заданий урока пройдены; тап — открыть урок, свайп вправо — корзина, по тапу на корзину bottom sheet с предупреждением, что при удалении урока все вложенные задания и карточки будут удалены без возможности восстановления («Удалить»/«Отмена», каскад `deleteLessonFx`); перетаскивание — порядок (на тач-устройствах — long-press 420мс, мышью — сразу вертикальным движением; тот же settle-механизм, что у заданий); кнопка edit в конце строки — редактирование урока; «Добавить урок» — экран создания.
- **Экран урока** (`features/sets/ui/SetsView.tsx`, экран `lesson{lessonId}`): шапка как у других вложенных экранов — стрелка и название урока по центру, справа меню «…» (bottom sheet) с пунктом «Редактировать урок» (логотипа и «Lexi» на вложенных экранах нет). Список активных заданий урока акцентным цветом (`Card color="accent"`, чтобы не путать с уроками), перед именем задания — зелёная галочка, если экзамен пройден (`set.examPassed`), счётчики выучено/не выучено (нули показываются), тап — приветственный экран задания (`set-intro`; если текста языка курса нет — сразу `cards`), свайп вправо — мягко удалить (корзина, подтверждение тапом), перетаскивание — порядок, кнопка edit в конце строки — редактирование задания, «Добавить задание» — экран создания задания в этом уроке.
- **Создание и редактирование урока** (`features/lessons/ui/LessonCreateView.tsx`, экран `lesson-create`): поле «Название урока» (`InputWithVoice` с микрофоном, язык пользователя; при создании подставляется «Урок N» — следующий номер по урокам курса), `Select` курса (по умолчанию текущий, смена переносит урок) и язык курса только для отображения — наследуется из курса, менять нельзя. В режиме редактирования (`lessonId`) заголовок «Изменить урок», предзаполненные поля, сохранение — `updateLessonFx` → `transport/lessons.updateLesson`. После создания (`createLessonFx`) открывается экран заданий нового урока. Урок можно также открыть на редактирование кнопкой edit в строке списка уроков.

Создание — `createSetFx` → `transport/sets.createSet` (задание с `lessonId` и карточками; после «Применить» сразу открывается экран `cards` нового задания), редактирование — `updateSetFx` → `transport/sets.updateSet` (имя, `lessonId`, тексты пар; для карточек без пары при смене языка курса тексты ремапятся, новые пары добавляются новыми карточками).
- **Приветственный экран задания** (`features/set-text/ui/SetTextView.tsx` в режиме `welcome`, экран `set-intro{setId}`): открывается тапом по заданию в списке урока, кнопкой «Перейти к следующему заданию» на экране карточек (если заполнен текст языка курса; иначе сразу `cards`) и кнопкой текста на экране карточек (если у задания есть текст хоть на одном языке; иначе открывается редактор `set-text`). В шапке — стрелка и название задания; текст показан как на экране «Текст задания» (табы языков, сегменты `parseWords` с выбором/объединением и тултипом перевода по удержанию), кнопки edit нет. Внизу — «Далее»: при входе с экрана карточек (предыдущий экран стека — `cards` того же задания) — `popScreen` обратно на карточки, иначе `replaceScreen` → `cards{setId}` (в истории экран не остаётся).
- **Карточки** (`features/cards/ui/CardsView.tsx` + `FlashCard.tsx`): колода до 3 карточек, тап — флип (CSS 3D), стороны берутся из `texts` по языкам пользователя/курса (лицевая по умолчанию — язык курса, обратная — язык пользователя; `CardSet.swapped` меняет их местами), свайпы: влево «выучено», вправо «позже», вверх «удалить» (порог 110px), при свайпе — вибрация через мост (`transport/haptics.ts`: вправо короткий импульс 20мс, влево — вдвое длиннее 40мс; в браузере без моста no-op), подписи-подсказки жестов; на видимой стороне верхней карточки — кнопки с иконками: «Изменить» открывает `card-create{setId, cardId}` с предзаполненными текстами карточки, и звука (показывается, если доступна озвучка — Web Speech API в браузере или мост в Android): озвучивает текст этой стороны (`speakFx` → `transport/speech.ts`; в Android сначала скачанный локальный нейроголос, иначе системный TTS, локаль по ISO-коду языка), при ошибке сообщение появляется строкой в карточке (`speakErrorText`: «Нет голоса для этого языка», «Озвучка недоступна на устройстве», «Скачайте голос в Настройки → Озвучка», «Обновите приложение»); под текстом лицевой стороны по центру — кнопки проверок (показываются, если `canRecognize()` / всегда): микрофон «Проверить произношение» и кнопка ввода «Проверить ввод текста» (`IconKeyboard`); произношение проверяется по **языку курса** (кнопки — только на лицевой стороне): `recognizeFx` → `transport/recognition.ts` распознаёт речь на языке курса (side 'front'; в Android при недоступности системного ASR скачивается офлайн-модель sherpa-onnx, прогресс — `$asrStatus` через `asrStatus`), `lib/pronunciation.ts: assessPronunciation` сравнивает услышанное с текстом языка курса (нормализация, выравнивание слов), вердикт записывается в `card.voiceCheck` (`good` → `true`, иначе `false`, ошибка распознавания не меняет), в карточке одной строкой — «Принятно!» или `Ошибка! Услышано "<услышано>", нужно <текст языка курса>`; ошибки распознавания выводятся этой же строкой в карточке (`recognizeErrorText`), во время записи кнопка пульсирует (`voiceCheck === null` — цвет `accent-over`), а вместо статуса обычным текстом цветом слова — «говорите» с бегающими точками (при скачивании ASR — прогресс загрузки; повторный тап по микрофону останавливает распознавание — `cancelRecognizeFx` → `cancelRecognition`); кнопка ввода раскрывает на месте кнопок поле с кнопками «ОК» (`IconCheck`) и «Отмена» (`IconClose`, прячет поле без проверки), ответ сравнивается с текстом языка курса (`lib/checks.ts: isAnswerCorrect`, регистр/ё/пунктуация) и пишется в `card.writeCheck`; кнопки окрашены по состоянию проверки (null — серые, true — зелёные, false — красные), под ними показывается одна строка (не скрывается по таймауту — только заменяется новым сообщением или сбрасывается при смене карточки): «Принятно!», `Ошибка! Услышано "<услышано>", нужно <текст языка курса>` (микрофон), `Ошибка! Нужно <текст языка курса>, ваш текст <текст>` (ввод); ошибки распознавания и озвучки — этой же строкой (только на лицевой стороне карточки), со звуком (`lib/sounds.ts: playSuccess/playError`, `unlockSounds` по тапу) и вибрацией (`vibrateSuccess`/`vibrateError`); если в настройках включён `learnAfterChecks` и обе проверки успешны, через 2 секунды после статуса карточка с анимацией уезжает в выученные; клик не переворачивает карточку и не начинает свайп (stopPropagation на pointerdown/click); фильтры «выучено/не выучено» с количеством; между ними по центру — кнопка с иконкой текста (`IconViewList`, aria-label «Текст задания») с переходом на приветственный экран `set-intro` при наличии текста (иначе — редактор `set-text`; активна всегда); меню «…» (bottom sheet): «Редактировать» (открывает `set-create{setId}`), «Поменять местами» (переключает `CardSet.swapped` — стороны карточки меняются местами вместе со звуком, проверки продолжают проверять язык курса), «Удалить все карточки» (мягко, по текущему фильтру), «Восстановить удалённые», «Сбросить» (bottom sheet `ConfirmSheet` с текстом «Вы уверены, что хотите сбросить это задание к первоначальному состоянию?» и кнопками «Да»/«Отмена»; по «Да» — `resetSetFx` → `transport/sets.resetSet`, локальные фильтры/сессия сбрасываются), «Удалить задание» (безвозвратно: `deleteSetFx` удаляет задание с карточками, перед этим — инлайн-подтверждение в области колоды, затем `popScreen`); пустые состояния и финалы: «Начать сначала» (когда всё просмотрено, но есть невыученные), «Все карточки выучены» + «Перейти к следующему заданию» (следующий задание берётся в рамках урока, иначе возврат на экран урока); в фильтре «выучено» после просмотра всех выученных — «Повторить» (сбрасывает сессию просмотра), а если выученных нет — пустой экран «Нет выученных карточек»; когда все неудалённые карточки выучены, нижняя кнопка «Добавить» заменяется на «Экзамен» (открывает `set-exam{setId}`).
- **Экзамен задания** (`features/set-exam/ui/SetExamView.tsx`, экран `set-exam{setId}`): открывается кнопкой «Экзамен» на экране карточек. В шапке — стрелка и «Экзамен». Показывается только лицевая сторона карточки (слово языка курса) без возможности перевернуть и без кнопок — под карточкой одна круглая кнопка микрофона. Тап по микрофону запускает распознавание (`recognizeFx` на языке курса), производится оценка произношения: при вердикте `good` — «Принятно!», иначе `Ошибка! Услышано "<услышано>", нужно <текст языка курса>`, со звуком и вибрацией. На слово даётся 3 попытки: после первой и второй неудачной попытки результат не засчитывается и карточка не меняется — сообщение дополняется «Осталось попыток: N», можно сразу повторить; после успеха или третьей неудачи результат засчитывается и через 1,5 с автоматически показывается следующая карточка. Ошибка распознавания (не расслышали, нет доступа) выводится сообщением, карточка не меняется и попытку не расходует — можно повторить. Очередь — все неудалённые карточки с текстом языка курса, порядок как в колоде. Когда все карточки проверены, показываются результаты в карточке как у текста задания (`TextPanel`): по центру жёлтый смайлик 80×80 (улыбка при отсутствии ошибок, грустный — иначе; вместо прежней галочки и заголовка «Результаты теста»), ниже две строки «Правильных ответов»/«Ошибок» — подписи `contrast-primary` крупнее по левому краю, цифры по правому краю (верные — `positive-text-and-icons`, ошибки — `negative-text-and-icons`); внизу на всю ширину «Пройти тест снова» (сбрасывает результаты и начинает тест заново) и «Вернуться к обучению» (`popScreen` на карточки), карточка занимает всю остальную высоту. При успехе играется `playSalute` и запускается `shared/ui/Confetti`, при неудаче — `playDisappointment`; при уходе экзаменационные данные сбрасываются. ## Android-обёртка

- `/Users/a.smirnov/p/lexi-android` — отдельный репозиторий (создан из шаблона `/Users/a.smirnov/p/android-webview-template`): WebView-обёртка Lexi с мостом `vibrate`/`deviceInfo`/`scanText`/`speak`, OCR на Tesseract4Android (вшиты ru/en, остальные языки скачиваются при первом использовании).
- URL веб-приложения настраивается в `app/webview.properties` (debug → `webview.devUrl`, release → `webview.prodUrl` = GitHub Pages).
- Аппаратная кнопка «назад»: `MainActivity` выполняет в WebView `(window.__lexiBack && window.__lexiBack()) === true`; веб-приложение регистрирует `window.__lexiBack = handleAndroidBack` (`main.tsx` → `features/navigation/store`), который при открытом bottom sheet закрывает его (`closeTopBottomSheet`) и возвращает `true`, иначе при стеке больше одного экрана делает `popScreen()` и возвращает `true` (как кнопка «назад»), иначе — переход по истории WebView/выход из приложения; `handlingBack` сбрасывается по таймауту, чтобы обработчик не «залипал».
- Кнопка «Сканировать текст» на экране `text-add` работает через `lib/nativeBridge.ts`; в браузере она скрыта.
- Вибрация при свайпах карточек — `transport/haptics.ts` → `callNative('vibrate', { durationMs })` (в Android `NativeBridge` использует `VibrationEffect.createOneShot`, ограничение 1–10000мс); в браузере вызовов нет.
- Озвучка карточек — `callNative('speak', { text, lang })`: `speech/SpeechService.kt` выбирает способ — скачанный локальный нейроголос (`speech/LocalTts.kt`) → системный `TextToSpeech` (`speech/SpeechSynthesizer.kt`, очередь до `onInit`, `QUEUE_FLUSH`; в манифесте — `<queries>` с `TTS_SERVICE` для Android 11+) → ошибка `voice_missing`; в браузере и без моста — Web Speech API.
- Распознавание речи — `callNative('recognizeSpeech', { lang })`: `speech/RecognitionService.kt` выбирает способ — системный `SpeechRecognizer` (`ACTION_RECOGNIZE_SPEECH`, локаль по языку, до 3 вариантов и confidence) → on-device (`createOnDeviceSpeechRecognizer`, Android 12+) → офлайн-модель NeMo FastConformer CTC через `speech/OfflineAsr.kt` (AudioRecord + VAD + `OfflineRecognizer`, языки ru/en/es/fr/it/de, ~97 МБ, `speech/AsrManager.kt` качает tar.bz2 с GitHub по нажатию микрофона, прогресс — `asrStatus`, `deleteAsr` — удалить модель); запрашивает `RECORD_AUDIO` в рантайме, ошибки — `permission_denied`/`no_speech`/`network`/`busy`/`language_not_supported`/`asr_download_failed`; `cancelRecognizeSpeech` останавливает распознавание (системный `cancel()`, офлайн — флаг отмены); синхронный `hasRecognition()` отдаёт доступность (web зовёт через `callNativeSync`); в браузере — Web Speech API (`webkitSpeechRecognition`), в Android WebView не работает. В манифесте — `RECORD_AUDIO` и `<queries>` с `android.speech.RecognitionService`.
- Офлайн-голоса — sherpa-onnx (Apache-2.0): AAR `app/libs/sherpa-onnx-1.13.8.aar` (нативные либы только arm64-v8a/armeabi-v7a, APK ~96 МБ) + Piper-модели (`speech/VoiceCatalog.kt`), скачиваются по кнопке на экране «Озвучка» (~64–80 МБ): сначала HuggingFace `csukuangfj/vits-piper-<id>` (`.onnx` + `tokens.txt`), при ошибке — GitHub-релиз `tts-models` (tar.bz2 через commons-compress); всё кладётся в `filesDir/tts`, общий `espeak-ng-data` вшит в APK (`assets/tts/espeak-ng-data.zip`), синтез и воспроизведение — через AudioTrack. Управление — мост `ttsVoices`/`downloadVoice`/`deleteVoice` (`speech/VoiceManager.kt`); ошибки загрузки приходят в `error` с деталями.
