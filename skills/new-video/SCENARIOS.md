## Заметки по съёмке

- Общий ролик (`overview`, 3:35) — три шага, всё озвучивает диктор (edge-tts `ru-RU-DmitryNeural`), тултипов нет: загрузка курса → задание (текст → карточки, 3 верно + «kitchen» в невыученные) → тест (4/4). Стартовое состояние — свежая установка (курсов нет, онбординг пройден). Сценарии: `scenarios/overview.md` (текст) и `overview.cjs` (запись). Особенности: задание и тест обрезаются до 4 карточек `eval`-шагом; переворот — тач-тапом (`touch: true`); озвучка слов — Samantha, проговаривание в тесте — Daniel, диктор — Dmitry.
- Ролик `task` (2:52) — «Работа с заданиями»: цель текста и карточек, перевод слова удержанием (`hold`), русская версия текста, создание своего задания со сканированием (мок Android-моста через `initScripts`), выбор слов, переводы (заглушка `routes`), тест в авто-режиме (очередь слов в мок-мосте). Сценарии: `scenarios/task.md` / `task.cjs`.
- Тестовый фрагмент `narrated-load-test` (~56 с) — предпросмотр «загрузка курса с диктором»; его текст встроен в шаг 1 `overview`, сам фрагмент остаётся как эталон формата.
- Пауза шага действует и на свайпы (внешний `pause` у `swipe`); для диктора пауза = реплика + ~0,8 с, замер — `engine/measure-tts.cjs`.
- Ролик `settings` (3:15) — «Настройки и данные»: разделы настроек, темы и подробный разбор «Данных». Импорт показывается без нативного диалога: `eval`-шаг собирает JSON-бэкап (версия читается из `app/src/transport/backup.ts`) и подкладывает его в скрытый `input[type=file]` через `DataTransfer`; реальный импорт и сброс не доводятся до конца (импорт увёл бы на «Курсы», сброс перезагрузил бы приложение) — нажимается «Отмена». Экспорт настоящий: файл скачивается, `popScreen` сам возвращает на «Данные». Сценарии: `scenarios/settings.md` / `settings.cjs`.
- Android-ролики: движок `new-video` работает только в браузере; для устройства — запись через adb/Maestro (тап/ввод) + `adb shell screenrecord`, либо мок моста в браузере, если нативная часть не важна.
- Ролик про проверки (`card-checks`) требует непохожего слова для ошибки: проверка в Lexi прощает созвучные оговорки (см. «Частые ошибки» в SKILL.md).
- Проверка засчитывает слово при совпадении первой буквы и близкого согласного скелета, а короткие слова (после сжатия удвоений ≤4 букв) — вообще при любом услышанном слове: для ошибки бери длинное слово с другой первой буквой (в `overview` — «banana» для «kitchen»).
