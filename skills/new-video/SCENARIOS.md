# Бэклог видеоинструкций

Порядок — приоритет съёмки. `id` = имя файлов (`app/public/videos/<id>.mp4|.webm|.jpg`) и сценария (`skills/new-video/scenarios/<id>.cjs`). После съёмки отмечай строку ✅ и добавляй сценарий рядом со скилом.

## Общий (P0)

| id | Название на карточке | Что показываем | Платформа |
| --- | --- | --- | --- |
| `overview` | «Знакомство с Lexi» ✅ снят | Сквозной путь за 40–60 с: курсы → вкладка «Уроки» → урок → задание (текст задания) → «Далее» → карточки: переворот, свайп «выучено», озвучка → проверка произношения («Принято!») → «Тест» → результаты. Задача — за минуту объяснить, как устроено приложение. | браузер |

## Заметки по съёмке

- Общий ролик (`overview`) снят по трём сценам: загрузка курса → задание на 4 карточки → тест. Подробности — `scenarios/overview.cjs`.
- Android-ролики: движок `new-video` работает только в браузере; для устройства — запись через adb/Maestro (тап/ввод) + `adb shell screenrecord`, либо мок моста в браузере, если нативная часть не важна.
- Ролик про проверки (`card-checks`) требует непохожего слова для ошибки: проверка в Lexi прощает созвучные оговорки (см. «Частые ошибки» в SKILL.md).
- Проверка засчитывает слово при совпадении первой буквы и близкого согласного скелета: для ошибки бери слово с другой первой буквой (в `overview` — «Sunday» вместо «Tuesday»).
