# Сценарий ролика «Загрузка курса с диктором» (`narrated-load-test`)

- Предпросмотр: `$TUT_OUT/narrated-load-test.mp4` · Программа записи: `scenarios/narrated-load-test.cjs`
- Длительность: ~55 с · Кадр: 390×844, тёмная тема
- Статус: тестовый фрагмент; после одобрения встраивается в основной ролик (`overview`, шаг 1).

## Цель

Проверить формат «все действия комментирует диктор»: каждая реплика отвечает, **что делаем**
и **зачем**. Тултипов нет. Если формат подходит — шаг 1 основного ролика заменяется на этот.

## Что используем

- Диктор — нейросетевой голос edge-tts `ru-RU-DmitryNeural` (`NARRATOR` в сценарии).
- Паузы = длина реплики + ~0,8 с, чтобы голос не накладывался сам на себя.
- Экран: «Курсы» после свежей установки (пустой список — «Пока нет ни одного курса»); в конце — список уроков загруженного курса.

## Шаг 1 — загрузка курса

- **Титр:** «Шаг 1» — «Для начала загрузим готовый курс.»
- **Тултипов нет** — всё объясняет диктор.

| Действие | Реплика диктора (что + зачем) | Реплика → пауза |
| --- | --- | --- |
| Титр «Шаг 1» | Начнём с загрузки готового курса — создавать его самому не нужно. | 5,1 с → 3,2 с |
| Тап «Добавить курс» | Открываем добавление курса. | 2,8 с → 3,7 с |
| Тап «Найти готовый» | Выбираем «Найти готовый» — откроется каталог курсов. | 4,7 с → 5,5 с |
| Тап «Выберите уровень» | Выбираем уровень владения языком. | 3,3 с → 4,2 с |
| Тап «Beginner» | Beginner — уровень для начинающих: в каталоге останутся подходящие курсы. | 5,7 с → 6,6 с |
| Тап «Знакомство» | Отмечаем курс «Знакомство» — галочка показывает, что скачаем именно его. | 6,0 с → 6,9 с |
| Тап «Загрузить» | Нажимаем «Загрузить» — приложение скачает курс и добавит его в ваши. | 5,5 с → 6,4 с |
| Тап «Знакомство (Ru-En)» | Открываем загруженный курс, чтобы посмотреть уроки. | 4,3 с → 5,1 с |
| Финал: список уроков | Курс готов: уроки перед вами. | 3,2 с → 4,0 с |

- **Результат шага:** курс «Знакомство» в списке, открыт экран уроков.

## Звук

Только диктор (6+3 реплики, все — `voice: NARRATOR`). Между репликами тишина. Длины
реплик измерены по edge-tts заранее, паузы выставлены в сценарии.
