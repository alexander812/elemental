# Сценарий ролика «Настройки и данные» (`settings`)

- Ролик: `app/public/videos/ru/settings.{mp4,jpg}` · Программа записи: `scenarios/settings.ru.cjs`
- Длительность: ~3:15 · Кадр: 390×844, тёмная тема · Постер: «Курсы» с курсом «Знакомство (Ru-En)»
- Платформа: браузер · Все действия комментирует диктор (что делаем и зачем), тултипов нет
- Статус: опубликован.

## Цель

Показать, где приложение подстраивается под пользователя: какие есть разделы настроек и зачем
каждый, как переключать тему и как устроен раздел «Данные» — экспорт в файл, импорт и сброс.
После ролика понятно, что менять под себя и как не потерять свои курсы.

## Что используем

- Готовый курс **«Знакомство (Ru-En)»** с двумя уроками («Новые соседи», «Давайте познакомимся»)
  и двумя заданиями — чтобы в экспорте было что выбирать, а в импорте был осмысленный файл.
- **Мок импорта**: в браузере нет нативного выбора файла — файл-бэкап подкладывается в скрытый
  `input[type=file]` через `DataTransfer` (`eval`-шаг). Версия формата читается из
  `app/src/transport/backup.ts`, имя файла — с сегодняшней датой.
- **Озвучку языков (раздел «Озвучка») не показываем**: в браузере его нет (только Android),
  и по просьбе — без скачивания голосов. Раздел «Данные» показан подробно, с импортом и сбросом.

## Правила

- Диктор — `edge:ru-RU-DmitryNeural`; паузы = реплика + ~0,9 с; титры разделяют шаги.
- Темы переключаются тапом по radio — приложение меняется сразу; в конце возвращаем тёмную.
- Импорт — только показ карточки файла и «Отмена»: файл дублирует текущие уроки, реальный импорт
  увёл бы на «Курсы». Сброс — только шит подтверждения и «Отмена»: реальный сброс перезагрузил бы
  приложение и оборвал запись.
- Экспорт — настоящий: отмечаем один урок, жмём «Экспортировать», файл реально скачивается,
  приложение само возвращается на «Данные».

| Тап «Настройки» | Открываем настройки — пройдёмся по каждому разделу. |
| Тап «Язык» | Раздел «Язык» — здесь выбирают, на каком языке показывать переводы и подсказки. |
| Назад | — |
| Тап «Проверки» | Проверки решают, как тренировать слова: произносить вслух или писать вручную. |
| Экран «Проверки» | А свитч «Переносить в выученные» сразу отметит слово выученным после верного ответа. |
| Назад | — |
| Тап «База знаний» | Если что-то забыли — в «Базе знаний» можно пересмотреть видеоинструкции. |
| Назад | — |
| Тап «О приложении» | «О приложении» — версия и дата сборки, а режим дебага подскажет, что услышала модель, если проверка не удалась. |
| Назад | — |

- **Результат шага:** пройдены Язык, Проверки, База знаний, О приложении; понятно, зачем каждый.

## Шаг 2 — тема оформления

- **Титр:** «Шаг 2» — «Выберем тему оформления.»
- **Экран:** меню «Настройки» → экран «Тема» с шестью темами.

| Действие | Реплика диктора |
| --- | --- |
| Титр «Шаг 2» | Теперь про оформление: тему каждый выбирает под себя. |
| Тап «Тема» | В приложении шесть тем: светлые, тёмные и цветные. |
| Тап «Светлая» | Светлая — для дневного времени. |
| Тап «Терракота» | Терракота — тёплые бежевые оттенки. |
| Тап «Аметист» | Аметист — тёмная тема с фиолетовыми акцентами. |
| Тап «Тёмная» | Вернёмся к тёмной — это тема по умолчанию. |
| Назад | — |

- **Результат шага:** тема меняется сразу; выбранная — «Тёмная».

## Шаг 3 — раздел «Данные» (подробно)

- **Титр:** «Шаг 3» — «Подробнее про раздел «Данные».»
- **Экран:** меню «Настройки» → «Данные».

| Действие | Реплика диктора |
| --- | --- |
| Титр «Шаг 3» | Отдельно остановимся на разделе «Данные» — он отвечает за сохранность курсов. |
| Тап «Данные» | Здесь три действия: экспорт, импорт и сброс. |
| Тап «Экспортировать» | Экспорт сохраняет выбранные уроки в файл — например, чтобы перенести их на другое устройство. |
| Снятие отметки «Давайте познакомимся» | Отметим уроки, которые войдут в файл: оставим только «Новые соседи». |
| Тап «Экспортировать» (кнопка) | Нажимаем «Экспортировать» — приложение сохранит файл. |
| Экран «Данные» | Файл можно отправить себе на почту или сохранить в облаке. |
| Тап «Импортировать» | Импорт — обратное действие: выбираем файл с копией данных. |
| Карточка файла | Приложение прочитает файл и покажет, что внутри: курсы, уроки, задания и карточки. |
| Экран «Данные» | «Слияние» добавит уроки из файла к текущим, «Замена» полностью заменит все данные приложения. |
| Тап «Отмена» | Отменим импорт — эти уроки уже есть в приложении. |
| Тап «Сбросить данные» | Сброс возвращает приложение к начальному состоянию — например, если хотите начать всё заново. |
| Шит подтверждения | Курсы, уроки и настройки удаляются без возможности восстановления, поэтому приложение просит подтверждение. |
| Тап «Отмена» | Отменим — данные нам ещё пригодятся. |
| Экран «Данные» (финал) | Теперь вы знаете, где настроить приложение под себя и как сохранить курсы в файл. |

- **Результат шага:** показаны все три действия раздела; итог — экран «Данные» с нетронутыми данными.
