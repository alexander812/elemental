# Сценарий ролика «Работа с заданиями» (`task`)

- Ролик: `app/public/videos/ru/task.{mp4,jpg}` · Программа записи: `scenarios/task.ru.cjs`
- Длительность: 2:52 · Кадр: 390×844, тёмная тема · Постер: «Курсы» с курсом «Знакомство»
- Статус: опубликован.

## Цель

Объяснить, как устроено задание и как создать своё: текст — главное в задании, карточки учат
слова и выражения, чтобы читать и понимать текст. Показать перевод слова по удержанию, русскую
версию текста, создание задания со сканированием текста и тест в автоматическом режиме.
Все действия комментирует диктор (что делаем и зачем), тултипов нет.

## Что используем

- Готовый курс **«Знакомство»** (ru-en) с уроком **«Новые соседи»** и заданием **«Доброе утро»**
  (текст и 10 карточек из каталога) — на нём разбираем текст.
- Своё задание: текст про субботнее утро у Картеров «сканируется» камерой (мок Android-моста),
  из текста отмечаются слова pancakes, newspaper, yard, monkeys, elephants.
- **Моки** (в браузере нет нативной части):
  - `initScripts` — `window.AndroidBridge`: кнопка «Сканировать текст», распознанный текст,
    распознавание речи (очередь слов для авто-режима), установленный артефакт ASR;
  - `routes` — заглушка переводчика (словарь en → ru), чтобы переводы в кадре были верными
    и ролик не зависел от сети.

## Правила

- Диктор — `edge:ru-RU-DmitryNeural`; паузы = реплика + ~0,8 с; титры разделяют шаги.
- Перевод слова — длинное нажатие (`hold`, 3,2 с): тултип виден, пока держишь.
- Тест — автоматический режим: проверки идут раз в ~2,46 с, «пользователь» отвечает голосом
  Daniel (очередь слов в мок-мосте), тайминги реплик рассчитаны от шага с кнопкой Play.

## Шаг 1 — текст задания

- **Титр:** «Шаг 1» — «Разберём задание: текст и карточки.»

| Действие | Реплика диктора |
| --- | --- |
| Титр «Шаг 1» | Разберём задание: текст и карточки. |
| Тап «Знакомство (Ru-En)» | Открываем курс «Знакомство». |
| Тап «Новые соседи» | Заходим в урок «Новые соседи». |
| Тап «Доброе утро» | Открываем задание «Доброе утро». |
| **Первый экран — текст задания (цель!)** | Перед вами текст задания. Основная задача — научиться читать и понимать этот текст. |
| Долгое нажатие на «windowsill» | Незнакомое слово можно перевести, не выходя из задания: нажмите на него и удерживайте. → тултип «подоконник» |
| Тап «Русский» | Текст легко переключить на русский и читать по-русски. |
| Тап «Далее» | Посмотрим карточки: они созданы из слов и выражений этого текста. |
| Экран карточек | Выучив карточки, вы будете понимать текст без перевода. |
| Назад к уроку | Вернёмся к уроку и создадим своё задание. |

- **Результат шага:** понятно, что текст — главное в задании, карточки учат слова из него.

## Шаг 2 — своё задание из своего текста

- **Титр:** «Шаг 2» — «Создадим своё задание: отсканируем текст и выберем слова.»

| Действие | Реплика диктора |
| --- | --- |
| Титр «Шаг 2» | Создадим своё задание: отсканируем текст и выберем слова для изучения. |
| Тап «Добавить задание» | В уроке можно добавить своё задание. |
| Ввод названия «Субботнее утро» | Даём задание название. |
| Тап по тексту задания | Теперь добавим текст задания. |
| Тап «Добавить текст» | Текст можно вставить, надиктовать или отсканировать. |
| Тап «Сканировать текст» | Сканируем: приложение распознает текст с камеры. → текст появляется в поле |
| Тап «Сохранить» | Текст распознан — сохраняем. |
| Отмечаем слова: pancakes, newspaper, yard, monkeys, elephants | Отмечаем незнакомые слова — из них создадутся карточки. |
| Тап «Создать карточки» | Создаём карточки из выбранных слов. |
| Меню задания → «Перевести всё» | Переведём слова: приложение подставит переводы. |
| Тап «Применить» | Задание готово — применяем. |
| Экран карточек нового задания | Задание создано: карточки со словами из нашего текста. |

- **Результат шага:** в уроке появилось своё задание с 5 карточками и своим текстом.
