# Сценарий ролика «Знакомство с Lexi» (`overview`)

- Ролик: `app/public/videos/overview.{mp4,webm,jpg}` · Программа записи: `scenarios/overview.cjs`
- Длительность: 3:35 · Кадр: 390×844, тёмная тема · Постер: экран «Курсы» (пустой список)
- Статус: опубликован (2-я версия — полностью озвучен диктором).

## Цель

Показать сквозной путь: загрузить готовый курс, пройти задание по карточкам (озвучка, проверка
произношения, переворот, свайп; ошибка → слово возвращается в невыученные), пройти тест
и увидеть результат. Каждое действие объясняет диктор: **что делаем и зачем**.

## Что используем

- Готовый курс **«Знакомство»** (ru-en), урок **«Новые соседи»**, задание **«Доброе утро»**.
- Задание и тест ограничены **4 карточками** (шаг `eval` после загрузки курса):
  good morning, to wake up, kitchen, coffee.
- Старт — свежая установка: **курсов нет** (экран «Пока нет ни одного курса»), онбординг
  пройден (движок сам ставит `app.onboarding`, если его нет в `seed`).

## Правила

- **Тултипов нет** — все действия комментирует диктор, этапы разделяют титры «Шаг 1/2/3».
- Диктор — нейросетевой голос `edge:ru-RU-DmitryNeural`; озвучка слов — Samantha (en);
  проговаривание слов в тесте — Daniel (en).
- Паузы = длина реплики + ~0,8 с (замер — `engine/measure-tts.cjs`), между репликами тишина;
  там, где у действия своя озвучка, реплика диктора вынесена в шаг-подводку.
- Переворот карточки — тач-тапом (`touch: true`); микрофон и озвучка только на лицевой стороне,
  поэтому проверка произношения идёт до переворота.
- Ошибку показываем на «kitchen» («banana»): короткие слова («coffee» → «cofe») проверка
  принимает при любом услышанном слове.

## Шаг 2 — задание

- **Титр:** «Шаг 2» — «Откроем урок «Новые соседи» и пройдём задание по карточкам.»

| Действие | Реплика диктора |
| --- | --- |
| Титр «Шаг 2» | Откроем урок и пройдём задание по карточкам. |
| Тап «Новые соседи» | Открываем урок — здесь список заданий. |
| Тап «Доброе утро» | Выбираем задание «Доброе утро»: откроется его текст. |
| **Первый экран — текст задания** (цель!) | Перед вами текст задания. Основная задача — научиться читать и понимать этот текст. |
| Там же | На основе этого текста задание создаёт карточки — они помогут выучить все незнакомые слова и выражения. |
| Тап «Далее» | Переходим к карточкам. |
| Карточка «good morning» | Слушаем слово — так запоминается его звучание. → проверка: Произносим — проверяем: скажите слово в микрофон («Принято!») → Тап по карточке переворачивает её — видим перевод → Свайп влево — слово выучено. |
| Карточка «to wake up» | Слушаем следующее слово → Произносим и проверяем («Принято!») → Переворачиваем → Выучено — свайп влево. |
| Карточка «kitchen» (ошибка) | Слушаем третье слово → Проверим ещё раз — произнесём слово неверно («Ошибка! Услышано "banana", нужно kitchen») → Переворачиваем — смотрим перевод → Свайп вправо — карточка остаётся в невыученных, повторим её позже. |
| Карточка «coffee» | Последнее слово — слушаем → Произносим верно («Принято!») → Переворачиваем → Свайп влево — выучено. |
| Финал | Три слова выучено, одно — в невыученных. Его можно повторить позже. |

- **Результат шага:** счётчики ✓3 / ✕1, экран «Вы посмотрели все карточки».
